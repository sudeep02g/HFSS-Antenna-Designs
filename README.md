# 📡 HFSS Antenna Design Projects

This repository contains antenna design and simulation projects completed during my Summer Internship on **RF Circuits and Antenna Simulation** using **ANSYS HFSS**.

## Overview

The objective of these projects was to understand antenna design principles and analyze the performance of different antenna structures through electromagnetic simulation. Various antenna geometries were designed, simulated, and optimized by modifying design parameters to achieve better performance.

## Projects Included

- 📌 Microstrip Patch Antenna
- 📌 MIMO Antenna
- 📌 Research Paper Based Antenna Designs

## Software Used

- ANSYS HFSS

## Parameters Analyzed

- Return Loss (S11)
- Gain
- VSWR
- Radiation Pattern
- Surface Current Distribution
- Bandwidth
- Electric Field Distribution

## Skills Gained

- RF & Microwave Engineering
- Antenna Design
- Electromagnetic Simulation
- Antenna Optimization
- Research Paper Implementation
- Performance Analysis
